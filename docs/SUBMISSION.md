- [x] Setup, architecture, command guide, limitations and attribution.

- [ ] Final demo video URL added to README; friend is preparing the video.

Animations may explain architecture; label reenactments and do not substitute them for evidence of execution. Do not claim automatic GitHub PR creation or unrestricted public access.
